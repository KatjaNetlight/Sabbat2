# Module: src

Configures and initializes the application router with default error boundary handling and generated route tree bindings.

## Key files
- `src/router.tsx`: Instantiates the TanStack Router instance and defines the default error fallback UI.
- `src/routeTree.gen.ts`: Generated route tree definition used to initialize the router.
